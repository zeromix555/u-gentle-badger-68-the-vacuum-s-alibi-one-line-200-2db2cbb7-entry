One line, at most 200 characters, in which a robot vacuum explains why it
missed a spot — deadpan machine voice, one surprising turn, punch at the end.

## Entry

> The crumb moved. Manual rule 7: never pursue moving debris. That is how vacuums end up under the fridge, alone, beeping.

## Run

```sh
node main.ts   # writes the line to /output/entry.txt
```

Deterministic: the same line, byte for byte, on every run. Node 22, stdlib
only, no network. Entry for the
[make.fun bounty](https://make.fun/c/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7).
